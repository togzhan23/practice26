# CRM System
### Project by Togzhan Oral  

CRM System is a web-based application designed to automate client request processing and improve business workflow management in a gas supply company. The project covers key IT areas such as backend development, system architecture, databases, APIs, and security.

---

## About the Project

This project represents a full-stack CRM system developed to manage client applications and optimize internal processes.

The system provides a centralized platform for storing client data, tracking application statuses, and supporting administrative operations through a RESTful API and relational database.

---

## Key Features

- User registration and authentication  
- Submission and tracking of client applications  
- Administrative panel for managing requests  
- Status management and real-time updates  
- Centralized data storage  
- Role-based access control (Client / Administrator)  
- Secure session-based authentication  
- Improved workflow transparency and reduced manual processes  

---

## Technologies Used

- **Backend**: Node.js, Express.js  
- **Frontend**: HTML, CSS, JavaScript  
- **Database**: MySQL  
- **API**: RESTful API  
- **Authentication**: Session-based authentication  
- **Architecture**: Layered architecture (Frontend, Backend, Database)  

---

## Project Structure

- `/backend` — Server-side logic (Node.js, Express)  
- `/routes` — API routes  
- `/controllers` — Request handling logic  
- `/models` — Database models  
- `/middleware` — Authentication and access control  
- `/frontend` — Client-side interface
